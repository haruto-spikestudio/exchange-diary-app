# 交換日記 画面試作

`index.html` をブラウザーで開く。スマートフォン幅のプレビュー用。すべて仮の画面・データで、実際のアカウント、招待、送信、データ保存は行わない。画面を閉じると入力内容は消える。

日記帳一覧の検索・絞り込み・表紙／リスト切替から、日記帳・順番、テンプレート選択、自由配置ページの編集、プレビュー、受け渡し、閲覧まで試せる。ページ上の入力欄に直接入力し、文字を追加できる。選択ツールでは文字欄やスタンプをドラッグまたは矢印キーで移動・削除できる。ペンは９種類・14色、スタンプは文字・モチーフ・キャラ・ふきだし・ワシテープ・フレームの６カテゴリで、いずれも仮のサンプル。消しゴムは手書きの触れた部分を消す。招待画面では仮のリンク作成から途中参加後の順番まで確認できる。

写真の追加、スキップ、ページの削除、コメントの投稿・削除、順番変更、自由絵文字の追加、配置物の回転・重なり順の変更は未実装。スタンプと文字欄の幅はスライダーで変更できる。順番や招待のルールは表示例であり、定員や有効期限の実際の判定は行わない。固定リアクションは画面上で切り替えられるが保存されない。初期版の仕様・提案とは分けて確認する。

プリクラのデコレーションを参考に、遊び心を残しつつ、ブルー・グリーン・オレンジなども使ったカジュアルな配色に調整した。色や素材は採用確定ではない。

トップバー・下部ナビ・ツールバー・パネル・カード類の「Liquid Glass」表現は、Flutter 本実装では pub.dev の [`liquid_glass_widgets`](https://pub.dev/packages/liquid_glass_widgets) と [`liquid_glass_easy`](https://pub.dev/packages/liquid_glass_easy) を基盤に組む前提。Web プロトタイプでは CSS の `backdrop-filter`、上縁のスペキュラ、淡い色収差、深めの投影を重ねて雰囲気を再現している。詳細は [技術構成の提案](../../docs/technology.md)を参照。

### 装飾操作（ストーリーズの参考画像をもとにした試作）

- ペンの種類・色・太さを選び、紙面に描けます。消しゴムは手書きの触れた部分を消し、描画・消去を直前の操作から戻せます。
- スタンプはカテゴリ内を検索して追加できます。追加後は「選択」に切り替わり、要素を直接ドラッグして移動、スライダーで大きさを変更できます。
- 「文字」で入力欄を追加し、フォント・サイズ・色を選べます。既存の文字欄もタップして変更できます。
- 編集内容はプレビューに反映されます。写真は表示例で、データの永続保存や実際の送信はありません。実機でのタッチ操作は未検証です。
