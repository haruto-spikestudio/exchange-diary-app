# 企画・要件

## コンセプト

友人同士が、昔の交換日記の懐かしさをスマートフォンで手軽に楽しむ。日記を書くことに加え、ページをデザインする楽しさも大切にする。

## 対象と体験

- 友人同士で使う。２人でもグループでも使える。
- 参加者だけが見られる日記帳で、順番にページを書いて次の人に渡す。
- 利用者は日記帳を複数持てる。日記帳ごとに参加者と順番を持つ。
- 書く期限は設けない。自分の番をスキップできるのは本人だけ。
- 渡されたページには、参加者がリアクションと短いコメントを付けられる。
- テンプレートは自由配置型とフォーム型の両方を用意し、書く人が選ぶ。さまざまなデザインとデコレーションを楽しめるようにする。
- 渡した後のページの修正機能は初期版には設けない。

## 利用の流れ（設計案）

1. 日記帳を作成し、友人を招待する。
2. 参加者の順番を設定する。
3. 自分の番になったら、テンプレートを選んでページを作る。
4. 内容を確認し、次の人に渡す。自分の番をスキップすることもできる。
5. 参加者が過去のページを読み、リアクションやコメントを付ける。

例えば順番が A → B → C のとき、B が自分の番をスキップすると C の番になる。本人以外はスキップできないため、本人が操作しない間は順番が進まない。

## 初期機能の候補

以下は現時点の設計案。実装順序や細かな挙動は未決定。

- アカウント、日記帳の作成、友人の招待、参加者と順番の設定
- 日記帳の一覧、過去のページの閲覧
- 両形式のテンプレート、文章・写真・デコレーション、手書き
- 下書き、渡す前の確認、ページを渡す操作、本人によるスキップ
- ページへのリアクションとコメント
- 自分の番になったときの通知

テンプレートや装飾の種類・数、自由配置や手書きの具体的な操作は試作を通じて決める。下書き、通知、プレビューの詳細も未決定。

## 非公開の基本方針

日記・写真・コメントなどは、その日記帳の参加者だけが見られる。アクセス制御、招待方法、退会時の扱いなど、具体的な実現方法は今後設計する。
