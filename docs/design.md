# デザイン

## 大切にする方向性

- Goodnotes のようにシンプルな画面に日記帳の表紙が並ぶイメージを参考にする。個別のデザインをコピーせず、紙の交換日記の懐かしさとスマートフォンでの手軽さを両立する。
- パステルのピンク・ブルー・ラベンダーの３色からテーマを選べるようにする。具体的な色味は試作で決める。
- テキストが中心。手書き、ステッカー、スタンプは補助の装飾として使う。フォントは初期は普通の読みやすいものとし、将来の選択機能を検討する。
- 日記帳一覧は表紙を並べ、自分の番や新着があるものを上に表示する。状態ごとの見た目を工夫する。双方に該当する場合の順位などは未決定。
- 日記ページは紙をめくるような見せ方にする。操作や演出の細部は試作で決める。
- シンプルなものから、カラフルで装飾の多いデザインまで選べるようにする。
- フォーム型と自由配置型の両方を用意し、書く人が選べるようにする。
- テンプレートとデコレーションの両方を楽しめるようにする。
- テンプレートは全体で８種類程度を目指す。フォームは空欄を許す。
- 自由配置はできるだけ制限のない体験を目指す。手書きは Instagram ストーリーズのような UI・UX を参考にする。

## 画面案（未確定）

- 日記帳一覧：表紙を並べ、自分の番と新着の日記帳を上に表示し、状態ごとに区別する。
- 日記帳・ページ閲覧：過去のページを読み、リアクション・コメントを付ける。
- テンプレート選択：２つの形式から、その回に使うページを選ぶ。
- ページ編集：テキストを主役に、写真・手書き・ステッカー・スタンプで飾る。具体的な操作 UI は試作後に判断する。
- 渡す前の確認：プレビューを表示し、渡した後は編集できない旨を注釈で伝える。

装飾や手書き、自由配置の使いやすさはスマートフォンで試作して確認する。実画面や試作品はまだ作成していない。

## 初期テーマ

パステルのピンク・ブルー・ラベンダーの３色から選べるようにする。色だけに頼らず文字やマークでも状態を区別し、文字の読みやすさを確保する。アプリ名・アイコン・日記帳の表紙デザインは未決定。
