# 技術構成の提案

2026-11-17 時点。Flutter で進める方向は確認済み。Supabase と Firebase Cloud Messaging を含む下記の構成案で進める方向を確認。契約・課金・実装・動作検証は行っておらず、詳細設計は今後検証する。サービスの料金・機能は導入前に再確認する。

## 推奨する構成

| 領域 | 候補 | 役割と検証事項 |
| --- | --- | --- |
| アプリ | Flutter / Dart | iOS から開始し、将来 Android・パソコン向けに展開。文字中心の編集、配置、手書き、ページめくりをまず実機で検証 |
| Liquid Glass 表現 | [`liquid_glass_widgets`](https://pub.dev/packages/liquid_glass_widgets) / [`liquid_glass_easy`](https://pub.dev/packages/liquid_glass_easy) | iOS 風 Liquid Glass はこの２パッケージ群を基盤に組む。`liquid_glass_widgets` はボタン・AppBar・Scaffold など完成ウィジェット、`liquid_glass_easy` は `LiquidGlassLens` などレンズ素材を提供。自前で backdrop blur を書かず、まずパッケージの標準部品で統一する |
| データ・認証 | Supabase の PostgreSQL / Auth | ユーザー、日記帳、参加者、順番、ページ、下書き、コメントなどを管理。メール・Apple サインインの連携を検証 |
| 写真 | Supabase Storage の非公開領域 | 写真を保存。必ずアクセス制御を実装し、退出・削除時に写真と一時 URL の扱いを確認 |
| アプリ側の重要処理 | PostgreSQL のトランザクションやサーバー側の処理 | 番の移動、10人の参加上限、削除同意、削除などを競合時も矛盾しないよう管理 |
| 通知 | Firebase Cloud Messaging | iOS では Apple の通知基盤との連携・通知許可も必要。通知文に日記本文を含めるかはプライバシーを踏まえて検討 |
| 監視・バックアップ | マネージド機能と追加手段を比較 | エラー監視、予算通知、データベースと写真のバックアップ、復元・削除反映を検証 |

[Supabase の Flutter 向け案内](https://supabase.com/docs/guides/getting-started/tutorials/with-flutter)では認証、データベース、ストレージの構成例が示されている。安全性は自動で保証されないため、[行レベルのアクセス制御](https://supabase.com/docs/guides/database/postgres/row-level-security)を設計し、写真へのアクセスも個別に制限・テストする。[通知の Flutter 向け案内](https://firebase.google.com/docs/cloud-messaging/flutter/get-started)も参照。

## 設計時に外せないこと

- 下書きは本人のみ、日記帳や写真は参加者のみがアクセス可能。権限をサーバー側で検証し、管理用の秘密鍵をアプリに含めない。
- 退出・ページ削除・最後の１人の退出・全員同意による削除・ブロックによる対象者の退出とその日記帳内の投稿削除を、写真を含めて矛盾なく処理する。ブロック前の影響確認、バックアップに残るデータの扱いも設計・明示する。
- 順番変更、参加、削除同意、同意の取り消しを複数人が同時操作しても壊れないようにする。全員同意による削除確定と取り消しが同時に届いたときの確定順序を設計する。
- 招待は参加の成立と１回限りの使用済み確定、期限・無効化・10人の上限確認を競合なく処理する。具体的な実装と検証は未実施。
- 下書きの後勝ちを採用するため、異なる端末の編集が上書きされ得る。保存完了の表示、サーバー側での保存順、通信不能時の扱いを試作・設計する。
- ページの内容を画像１枚だけに固定するか、テキスト・写真・装飾の配置データとして保存するかを検討。後者は端末間同期や表示再現に有利な一方、編集画面と互換性の設計が必要。
- 退会後に短時間有効な写真 URL が残るケースも含めて検証する。[Supabase の署名 URL の仕様](https://supabase.com/docs/guides/storage/security/signing-keys)では、URL は期限まで有効になり得る。アクセスの即時停止方針と整合する方法を設計する。

## 費用の参考

- [Apple Developer Program](https://developer.apple.com/programs/whats-included)：年99米ドル、または地域で表示される現地通貨額。実際の請求額は申込時に確認する。
- [Supabase 料金表](https://supabase.com/pricing)：試作用の Free は月0米ドル。Pro は月25米ドルからで、最初のプロジェクトを含む。利用量や追加構成で費用が変わる。Free のデータベース自動バックアップは含まれない。
- 仮に Pro の最低構成と Apple 年会費のみなら、**25米ドル/月 + 99米ドル/年 ÷ 12 = 約33.25米ドル/月相当**。税・為替・追加通信量・ストレージ・通知・写真バックアップ・その他サービスは含まず、実際の支払額ではない。データベースのバックアップが写真ファイルまで含むとは限らないため別途確認する。
- アプリの規模や写真量が未定のため、実際の月額費用はまだ見積もれない。無料枠を本番に使う場合も、バックアップと復旧方法を先に整える。
