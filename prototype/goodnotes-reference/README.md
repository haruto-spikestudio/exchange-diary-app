# 交換日記 画面試作

`index.html` をブラウザーで開く。スマートフォン幅のプレビュー用。すべて仮の画面・データで、実際のアカウント、招待、送信、データ保存は行わない。画面を閉じると入力内容は消える。

日記帳一覧の検索・絞り込み・表紙／リスト切替から、日記帳・順番、テンプレート選択、自由配置ページの編集、プレビュー、受け渡し、閲覧まで試せる。ページ上の入力欄に直接入力し、文字を追加できる。選択ツールでは文字欄やスタンプをドラッグまたは矢印キーで移動・削除できる。ペンは９種類・14色、文字とモチーフ・柄のスタンプは試作のサンプル。消しゴムは最後の線を１本取り消す。写真、コメント、自由絵文字などは表示例。招待画面では仮のリンク作成から途中参加後の順番まで確認できる。

プリクラのデコレーションを参考に、遊び心を残しつつ、ブルー・グリーン・オレンジなども使ったカジュアルな配色に調整した。色や素材は採用確定ではない。

トップバー・下部ナビ・ツールバー・パネル・カード類の「Liquid Glass」表現は、Flutter 本実装では pub.dev の [`liquid_glass_widgets`](https://pub.dev/packages/liquid_glass_widgets) と [`liquid_glass_easy`](https://pub.dev/packages/liquid_glass_easy) を基盤に組む前提。Web プロトタイプでは CSS の `backdrop-filter`、上縁のスペキュラ、淡い色収差、深めの投影を重ねて雰囲気を再現している。詳細は [技術構成の提案](../../docs/technology.md)を参照。

[Mobbin の Goodnotes](https://mobbin.com/apps/goodnotes-ios-3fe1cf71-b957-422e-87fd-1b5d04fa6649/93cd5331-75ba-5932-a1cd-414fc20bd928/screens)の一覧、[Apple Notes](https://mobbin.com/apps/apple-notes-ios-201a63f1-7499-4ebe-b92d-401605aa41bb/1782dd26-1259-4ebf-b402-384a81685971/screens)の検索・一覧、[5 Minute Journal](https://mobbin.com/apps/5-minute-journal-ios-595ba6e4-9f90-4000-ba54-efd4ea1283ff/59e50e27-93e1-47d0-85a6-e6c6736cb8ae/screens)の書くきっかけを示す画面を参考にした。編集ツールの構成は [Goodnotes の公開資料](https://support.goodnotes.com/hc/en-us/articles/13682253498767-Improved-User-Interface)も参考にしている。Mobbin の全画面は閲覧できていない。色や文言、テンプレートは未確定。

2026-11-20 追加調整：編集パネルは紙面に重ね、最初は閉じた状態にした。固定の紙面装飾を外し、スタンプを移動・削除できる形に統一。プレビュー後に受け渡し確認を追加し、一覧・招待画面のサンプル情報と文字・操作部品の見やすさも調整した。受け渡しや招待は引き続き画面上のサンプルで、実際の送信や保存は行わない。

2026-11-20 UX パス：[nijibox が紹介する参考サイト](https://blog.nijibox.jp/article/uiux_recommended_site/)群（Mobbin、Apple Notes、Goodnotes、Material 3、Collect UI、UX Archive など）で共通する現代モバイル UI パターンを踏まえ、横断的に整えた。
- 情報密度：ライブラリーの hero を圧縮、絞り込みチップと表示切替を1行に統合、表紙に「YOUR TURN」バッジを追加（リスト表示では小さなドット表現に）。日記帳詳細では現在担当のアバターを強調色で区別。
- エディタ：ツール列に論理グループの仕切り、選択中ツールの下線インジケーター、デコパネルは下部シート風のグラブハンドル表現に変更。
- 動き：タップ時の微細な押し込み、下部ナビと選択ツールの滑らかなインジケーター遷移、トーストのスライドアップと成功マークのポップイン。`prefers-reduced-motion` で無効化。
- タイポ・配色：`--text-xs〜--text-hero` / `--space-1〜--space-8` のスケールを定義。アクセント色 `--accent / --accent-deep` と `--muted-warm` を WCAG AA 準拠（4.5:1 以上）に調整。

2026-11-20 追調整：全体が暖色に寄りすぎていたため、背景（body / app）、ヒーロー、紙面周辺、通常の `notice`、影キャストを一段ニュートラル（ストーン系）に変更。テラコッタアクセントと `notice.turn` / 書く FAB / 現在担当アバター / Primary CTA は identity として残し、暖色を「現在の手番・次のアクション」の意味を持つ場所に集中させている。
