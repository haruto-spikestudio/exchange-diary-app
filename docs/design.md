# デザイン

## 大切にする方向性

- プリクラのデコ機能のように、ページを飾って交換する楽しさを主役にする。アプリ全体も明るく遊び心があり、特定の雰囲気に寄せすぎないカジュアルな方向を試す。ノートの一覧の分かりやすさは引き続き重視する。
- ピンクに加え、ブルー・グリーン・オレンジなど複数色を試す。テーマの数と具体的な色味は未確定。
- ペン・手書き・文字スタンプ・柄スタンプ・ステッカーを、テキストとともに楽しめるようにする。ペンやスタンプの具体的な種類は試作案であり未確定。
- 日記帳一覧は表紙を並べ、自分の番や新着があるものを上に表示する。状態ごとの見た目を工夫する。双方に該当する場合の順位などは未決定。
- 日記ページは紙をめくるような見せ方にする。操作や演出の細部は試作で決める。
- シンプルなものから、カラフルで装飾の多いデザインまで選べるようにする。
- 自由配置を基本とし、最初から入力欄を備えたテンプレートも用意する方向。入力欄にはページ上で直接テキストを打ち込む。フォーム型を別形式としては設けない。
- テンプレートとデコレーションの両方を楽しめるようにする。
- テンプレートは全体で８種類程度を目指すが、試作後に数を見直す。用意された入力欄は空欄を許す。
- 自由配置はできるだけ制限のない体験を目指す。手書きは Instagram ストーリーズのような UI・UX を参考にする。

## テンプレート案（未確定）

| 案 | 形式 | 特徴 |
| --- | --- | --- |
| ほっこり交換ノート | フォーム型 | 今日の出来事、うれしかったこと、みんなへの質問 |
| キラキラプロフィール帳 | フォーム型 | パステルカラーや装飾、好きなものなどの質問 |
| 写真アルバム | フォーム型 | 写真と、その思い出を書く欄 |
| 一問一答 | フォーム型 | 質問に答えながら気軽に書ける |
| シンプル方眼ノート | 自由配置型 | 方眼と余白を生かしたページ |
| 罫線入りの日記帳 | 自由配置型 | 文章を中心に書けるノート風 |
| スクラップブック | 自由配置型 | 紙風の背景に写真や装飾を配置 |
| おてがみ便箋 | 自由配置型 | 友人に手紙を書くようなページ |

上記８種類は過去の参考案であり、表中の「フォーム型」は当時の分類。現在は独立したフォーム型を設けず、必要な入力欄をページに置いた自由配置テンプレートとして検討する。利用者が別途調べるため、採用・初期版の内容・構成・色は未決定。

## 画面案（未確定）

- 日記帳一覧：表紙を並べ、自分の番と新着の日記帳を上に表示し、状態ごとに区別する。
- 日記帳・ページ閲覧：過去のページを読み、リアクション・コメントを付ける。
- テンプレート選択：入力欄のあるものを含む自由配置テンプレートから、その回に使うページを選ぶ。
- ページ編集：写真・手書き・文字や柄のスタンプで自由に飾り、入力欄にも直接書けるようにする。具体的な操作 UI は試作後に判断する。
- 渡す前の確認：プレビューを表示し、渡した後は編集できない旨を注釈で伝える。

画面の試作として Figma の静的画面と、[ブラウザー版](../prototype/goodnotes-reference/README.md)を作成した。ブラウザー版は仮データを使い、配置された入力欄への入力・移動や手書きの一部を試せる。Figma 版は以前の案であり、現在の方針をまだ反映していない。装飾や自由配置の使いやすさはスマートフォンの実機でまだ検証していない。

## 初期テーマ

パステル系を含む複数の色を比較し、色だけに頼らず文字やマークでも状態を区別する。テーマの数・色味、アプリ名・アイコン・日記帳の表紙デザインは未決定。
