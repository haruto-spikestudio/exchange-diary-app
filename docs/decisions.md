# 決定事項と検討事項

## 決定事項

2026-11-17、会話で確認。機能の希望と公開方針であり、初期版に全て含める決定ではない。

### これまでの決定

- 友人同士で使い、２人でもグループでも利用する。日記帳は複数作成できる。
- 日記帳は参加者だけが見られる。決まった順番で書き、期限は設けない。本人だけが自分の番をスキップできる。
- ページにリアクションと短いコメントを付けられる。
- 自由配置型とフォーム型のテンプレート、複数のデザインと装飾を用意する。
- 渡したページの編集は初期版に含めない。

### 今回の決定

- 一般公開を目指す。まず iOS アプリ、その後 Android、将来的にパソコン版も検討する。
- アカウント作成は複数の方法を組み合わせる。組み合わせの中身は未決定。
- 招待リンクは24時間有効。日記帳の参加者は最大10人。
- 最初の順番は参加順。開始後は参加者なら誰でもいつでも次の番以降の順番を変更できる。現在の担当者は変わらない。
- 途中参加を認め、途中参加者も以前のページを閲覧できる。
- テンプレートは全体で８種類程度を希望。フォームの空欄を許す。自由配置は制限のない体験を目指す。
- 手書きの操作は Instagram ストーリーズのような UI・UX を参考にする。
- 写真は１ページ５枚まで、端末の写真アプリから選ぶ。下書きは本人のみが見られ、自動保存し、別端末でも続けられる。
- 渡す前にプレビューを表示し、渡した後は編集できない旨を注釈で伝える。
- スキップした履歴を残す。スキップ時の確認画面や下書きの扱いは未決定。
- 参加者はいつでも退出できる。他の参加者を外す権限は設けない。退出者が書いたページ・コメントは削除し、退出後は本人も閲覧できない。退出者のページに付いた他の参加者のコメントとリアクションも削除する。
- 日記帳の削除は誰でも提案でき、参加者全員の同意を必要とする。未回答者がいる間は削除せず待つ。各参加者は削除実行前なら自分の同意を取り消せる。削除後は元に戻せない。
- コメントは編集不可。削除できるのはコメントを書いた本人。
- リアクションは固定の種類を用意し、１人が複数種類を付けられる。iOS の絵文字のような絵文字も使えるようにしたい。固定の種類と絵文字の選び方は要設計。
- 通知は各種用意し、種類別にオフにできるようにする。過去ページは時系列に加え、日付や書いた人で探せるようにしたい。
- 渡したページは書いた本人が削除できる。非表示機能は設けない。公開後の編集を将来追加するかは未決定。

### 追加決定（2026-11-17）

- 上記の順番変更の範囲、退出者のページに付いたコメント・リアクションの削除、全員同意までの待機、削除前の同意取り消し、削除後に戻せない扱いを確認。現在の番を本人以外が飛ばさないため、順番変更は次の番以降に限る。

## 検討事項

- 初期版とアップデートの機能分割。提案は [初期版・運用の提案](release-plan.md) を参照。
- アカウント作成方法の組み合わせ、技術構成、費用、運用担当。
- 招待リンクの発行者、無効化、再利用、期限切れ時の扱い、参加上限到達時の扱い。
- 担当者の退出や途中参加時の現在の番、変更後の順番の次の周以降への反映方法。
- 退出した人の写真・他のページに付けたリアクション・下書き、通常のページ削除時に付随するコメントやリアクション、最後の１人の退出・日記帳の扱い。
- 全員同意の集め方・有効期間・削除申請中の参加者変更、削除後のデータとバックアップ。
- ページ削除の確認方法と履歴、スキップの確認画面と下書き、同時編集や端末間同期の衝突時の扱い。
- テンプレートと装飾の具体的な内容・数、手書きと自由配置の操作、写真の詳細な制限。
- コメントの文字数上限、リアクションに使う絵文字の範囲と取り消し、通知の種類・既定値。
- 個別ページ・日記帳・アカウントの削除ポリシー、非公開のアクセス制御、バックアップ、報告・ブロック等の安全対策。

## 更新ルール

新しい判断は、決定日と理由が分かるよう記録し、関連する企画・デザイン文書にも反映する。過去の判断が変わった場合は、変更内容と理由が追えるように残す。提案は決定事項と区別する。
