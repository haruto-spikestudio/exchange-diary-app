# 決定事項と検討事項

## 決定事項

2026-11-17 時点、会話で確認した内容。

- 対象は友人同士。２人でもグループでも利用する。
- 日記帳は参加者だけが見られる。
- 決まった順番で交互に書く。書く期限は設けない。
- 自分の番をスキップできるのは本人だけ。
- ページにリアクションと短いコメントを付けられる。
- 自由配置型とフォーム型のテンプレートを両方用意し、自由に選べるようにする。
- テンプレートもデコレーションも複数種類用意し、さまざまなデザインを楽しめるようにする。
- 日記帳は複数作成できる。
- 渡した後のページの修正は、初期機能には含めない。

## 検討事項

- 対応プラットフォーム、技術構成、開発・運用方法。
- 招待方法と参加者の追加・退出、日記帳の削除、順番の設定・変更方法。
- 参加者の追加や退出による、過去ページの閲覧範囲と順番への影響。
- スキップの確認画面や履歴の見せ方、下書きがある場合の扱い。
- 各テンプレートと装飾の種類・数、手書き・自由配置の具体的な操作。
- 写真の取り扱い、フォームの空欄、下書きの保存方法や端末間の扱い。
- コメントやリアクションの変更・削除、通知の対象と設定。
- 渡したページの削除や、参加者・アカウントの退会時にデータをどう扱うか。
- 非公開を実現する認証・アクセス制御、招待リンクの保護、バックアップ。

## 更新ルール

新しい判断は、決定日と理由が分かるよう記録し、関連する企画・デザイン文書にも反映する。過去の判断が変わった場合は、変更内容と理由が追えるように残す。
