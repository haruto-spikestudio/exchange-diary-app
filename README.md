# 交換日記アプリ

友人同士が、紙の交換日記の懐かしさとページを飾る楽しさをスマートフォンで味わうためのアプリです。

## ドキュメント

- [企画・要件](docs/product.md)：対象、体験、ルール、初期機能の候補
- [デザイン](docs/design.md)：参考画像の特徴、テンプレート案、画面の方向性
- [決定事項と検討事項](docs/decisions.md)：決まったことと、これから決めること
- [初期版・運用の提案](docs/release-plan.md)：試作、初期版とアップデート、プライバシーと運用の案
- [技術構成の提案](docs/technology.md)：Flutter を中心とした構成と費用の参考
- [法務・公開時の確認](docs/legal-review.md)：国内公開に向けた法令・App Store 審査の確認事項

## 更新の仕方

仕様が決まったら該当する文書に反映し、重要な判断は「決定事項と検討事項」にも記録します。提案や未決定の内容は、確定した仕様と区別して書きます。実装状況や検証結果は、開発が進んだ時点で追記します。

現段階は企画・設計段階です。アプリの実装や実機検証はまだ行っていません。Flutter、Supabase、Firebase Cloud Messaging の構成案で進める方向を確認しています。契約・課金や詳細設計はまだです。
