# 交換日記アプリ

友人同士が、ペンやスタンプでページをデコレーションして交換する楽しさを、スマートフォンで味わうためのアプリです。

## ドキュメント

- [企画・要件](docs/product.md)：対象、体験、ルール、初期機能の候補
- [デザイン](docs/design.md)：参考画像の特徴、テンプレート案、画面の方向性
- [決定事項と検討事項](docs/decisions.md)：項目別の最新の結論、未決定事項と変更履歴
- [用語集](docs/glossary.md)：周、担当者、リアクションなどの意味
- [初期版・運用の提案](docs/release-plan.md)：試作、初期版とアップデート、プライバシーと運用の案
- [試作までの進め方](docs/work-plan.md)：判断が必要な論点、試作と公開前の進行案
- [技術構成の提案](docs/technology.md)：Flutter を中心とした構成と費用の参考
- [法務・公開時の確認](docs/legal-review.md)：国内公開に向けた法令・App Store 審査の確認事項
- [画面試作](prototype/goodnotes-reference/README.md)：仮データで一覧・編集・受け渡しを試せるブラウザー版

## 更新の仕方

仕様が決まったら該当する文書に反映し、重要な判断は「決定事項と検討事項」にも記録します。提案や未決定の内容は、確定した仕様と区別して書きます。実装状況や検証結果は、開発が進んだ時点で追記します。

現段階は企画・設計段階です。ブラウザーで操作できる画面試作はありますが、本番向けの実装や実機検証はまだ行っていません。詳細は[決定事項と検討事項](docs/decisions.md)を参照してください。
