# 用語集

企画で使う言葉と、まだ決めていない境界を整理する。詳細な仕様は [企画・要件](product.md) と [決定事項と検討事項](decisions.md) を参照。

| 用語 | 意味 |
| --- | --- |
| 日記帳 | ２〜10人の参加者で共有する交換日記のまとまり。１人が複数の日記帳に参加できる。 |
| ページ | 自分の番に作成し、プレビュー後に次の人へ渡す日記の１回分。 |
| 担当者・自分の番 | いまページを書く権利を持っている参加者・その人の順番。順番変更では現在の担当者は変わらない。 |
| 周（ラウンド） | 開始時に対象者を決め、その全員が書くかスキップすると完了する単位。途中参加者は次の周の最後に入る。未担当の人が退出・ブロックされたら対象から外し、残る対象者が全員完了していれば周を終える。 |
| スキップ | 担当者本人がページを渡さず自分の番を終え、次の人へ進める操作。履歴が残り、そのときの下書きは削除される。次の人以外を直接指定して渡す機能は設けない。 |
| 固定リアクション | アプリが事前に用意する種類から選び、ページに付ける反応。１人が複数種類を付けられ、本人は取り消せる。具体的な種類は未決定。 |
| 自由絵文字リアクション | 固定セットに加え、iPhone の絵文字キーボードから好きな絵文字を選ぶリアクション。入力・表示の詳細や取り消しの単位は未決定。 |
| フォーム型 | 用意された質問・入力欄に沿ってページを作るテンプレート。空欄を許す。 |
| 自由配置型 | ページ上に文章や写真、装飾を配置して作るテンプレート。できるだけ制限のない体験を目指すが、具体的な操作は試作で決める。 |
| 装飾 | テキストを中心としたページに添える手書き、ステッカー、スタンプなど。具体的な種類は未決定。 |
| 後勝ち | 同じ下書きを複数端末で編集した場合に、後から保存された内容を優先する方針。先の編集が上書きされることがあり、保存順の判定や警告表示は未決定。 |
| ブロック | 他の参加者を対象に、操作した日記帳から退出させ、その日記帳内の本人のページ・コメント・リアクションを削除する操作。対象ページ上の他者の反応も削除される。他の日記帳は対象外。解除・再参加等は未決定。 |
